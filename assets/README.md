# Assets — Image Files Required

Place the following files in this folder before deploying:

| File name          | Description                                             |
|--------------------|---------------------------------------------------------|
| `profile.jpg`      | Your professional profile photo                         |
| `cert-huawei.jpg`  | HCIA-Security V4.0 certificate (Huawei Talent Online)   |
| `cert-mahara.jpg`  | Cybersecurity For Beginners certificate (ITI Mahara-Tech)|
| `cert-zinad.jpg`   | Global Cyber Championship certificate (Zinad IT + ITI)  |
| `samy-akrm-cv.pdf` | Your CV / Resume PDF for the download button            |

## Notes
- Images should be JPG or PNG, reasonable quality (800–1600px wide recommended).
- The `cert-*.jpg` files are used as thumbnails in the Certifications section and opened full-screen in the lightbox.
- Filename casing matters — use lowercase as listed above.
