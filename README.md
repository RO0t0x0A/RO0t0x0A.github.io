## Setup

1. **Add your images** — Copy your photo and cert images into `assets/` as described in `assets/README.md`.
2. **Add your CV** — Place your PDF as `assets/samy-akrm-cv.pdf`.
3. **Open locally** — Open `index.html` in any browser. No server needed.
4. **Deploy to GitHub Pages** — Push to your repo, enable GitHub Pages on the `main` branch root.

## GitHub Pages Deployment

1. Push this folder to `https://github.com/RO0t0x0A/ro0t0x0a.github.io`
2. Go to **Settings → Pages** → Source: `Deploy from branch` → Branch: `main` → Folder: `/root`
3. Your site will be live at `https://ro0t0x0a.github.io`
